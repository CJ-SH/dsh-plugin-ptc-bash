This is the MIT licence text of the DeepSeek Harness `ptc` agent preset that
presets/ptc-bash/agent.cordis.yml is adapted from.

dsh 0.2.0-rc.1 ships that preset as `presets/ptc.patch.yml`
(`insert[0].config.plugins`) inside the package `@deepseek-ai/dsh-web-app`.

this file's name is kept so older references resolve, not because that package
